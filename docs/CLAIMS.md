# Product claim register

Every statement the website makes about Onjaal or Onjaal HRMS, and how much evidence stands behind it.
**Update this file whenever site copy changes.** Rule: nothing is presented as available unless it is *Verified*.

Audit date: V0 build. Method: full repository inspection. The repository contains only this marketing site
(no HRMS source code, screenshots, documentation or running application), so no HRMS capability could be verified.

| Claim on the site | Status | Basis / what would verify it |
|---|---|---|
| Onjaal is an early-stage company building practical business software | Stated by the founders | Founder brief |
| Onjaal HRMS is the first product and is in development | Stated by the founders | Founder brief |
| HRMS is human resource management software for employee records and everyday HR requests | Stated by the founders (purpose only) | Founder brief |
| The name Onjaal reflects the idea of a net / connection | Stated by the founders | Founder brief |
| Connected products are a long-term direction; none announced | Stated by the founders | Founder brief |
| Employee directory, leave requests with status timeline, "who's away" week view, home overview | **Concept only** | Illustrative screens with fictional people. Verify against the real product before calling any of them features. |
| Roles: HR team, employees, business owner or administrator | **Concept only** | Confirm the product's real user roles. |
| Feature list, pricing, release date | Unknown, correctly shown as "not yet published/announced" | Publish only when decided. |
| Any other Onjaal product | Does not exist publicly, shown as "none announced" | |

Not claimed anywhere: customers, testimonials, logos, statistics, certifications, awards, security or compliance
properties, integrations, AI capabilities, company address, phone number or legal entity details.

## Verification levels
1. **Verified**: exists in the real product and was seen working.
2. **Present, not production-ready**: exists but unfinished (label "in development").
3. **Planned**: decided but not built (label "planned").
4. **Unknown**: do not mention, or state plainly that it is not yet announced.
